# Changelog

This changelog tracks the starter-package layer around the HAPW Core. It does not rewrite historical validation records or imply HAPW 1.0.

## 0.2-public-candidate — release candidate

### Added

- a sanitized `v0.2-public-candidate` Core derivative that preserves the normative workflow while removing private/source-project provenance;
- a public-safe validator with generic structural, integrity, scope, license-identity, and secret-pattern checks;
- newcomer README and approximately-five-minute Quick Start;
- six domain-neutral project-control templates;
- local-filesystem, Google Drive, and GitHub adapter guidance plus the common adapter contract;
- concepts, authority, recovery, security, and limitations documentation;
- an unrelated low-stakes pantry-inventory example;
- the Apache License, Version 2.0 (`Apache-2.0`) as the release license;
- mechanical package validation and read-only continuous integration.

### Current release gates

- final public-safety review of the complete licensed frozen bundle is still required;
- a fresh unrelated-project bootstrap/recovery validation must pass in a separate formal test lane;
- public repository visibility requires explicit human authorization.

The current package remains **HAPW v0.2 public candidate** and is **not HAPW 1.0**.
