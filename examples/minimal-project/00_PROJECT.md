# Project

## Goal

Create a simple pantry inventory and a short list of staple items to buy before the next grocery trip.

## Success

All three pantry shelves have been checked, each staple item has a current whole-package count, and items below the chosen minimum have been added to one shopping list.

## Constraints

- Keep the exercise under 30 minutes.
- Track unopened package counts only; do not track prices or expiration dates.
- This is an illustrative example, not real household data.
